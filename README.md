# UK_Railway_Revenue_Dashboard

## Overview
An interactive Power BI dashboard analyzing UK railway ticket transactions, covering revenue performance, passenger purchase behaviour, and journey/service reliability.

## Dataset
~31,000 rows of UK railway transaction data, including ticket sales, journey details, and service outcomes.

## Dashboard Pages

### 1. Revenue Overview
- Total Revenue, Total Tickets, Avg Revenue per Station
- On-Time Rate % and Refund Rate %
- Revenue by Departure Station (bar chart)
  ![Revenue Overview](Revenue_Overview-Screenshot%202026-09-16%2015...png)

### 2. Purchase Behaviour
- Breakdown by Ticket Type, Ticket Class, Ticket Purchase Type
- Payment Method distribution
  ![Purchase Behavior](Purchase_Behavior-Screenshot%202026-09-16%2015...png)

### 3. Journey Performance
- Journey Status Overview (on-time, delayed, cancelled)
- Top Reasons for Delay
- Railcard Usage and Refund Requests
 ![Journey_Performance](Journey_Perfomance-Screenshot%202026-09-16%2015...png)

## Key Insights
- Identifies which departure stations generate the most revenue
- Highlights service reliability (on-time vs. delayed vs. refunded journeys)
- Surfaces the leading causes of delays to inform operational priorities
- Shows how passengers pay and purchase tickets, useful for pricing/channel strategy

## Tools Used
- Power BI (data modeling, DAX, visualization)
- Excel/CSV (data preparation)

## Skills Demonstrated
Data cleaning, DAX measures, dashboard design, KPI reporting, data storytelling
